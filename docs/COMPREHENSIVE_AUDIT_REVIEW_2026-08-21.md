# تقرير المراجعة الشاملة — أسناني قطر / MMC‑MMS

**تاريخ المراجعة:** 21 أغسطس 2026
**آخر إيداع متضمن إصلاحاً برمجياً:** `a2d2520` — مزامنة نوع RPC للتحقق الهاتفي مع مخطط Supabase الحي.
**آخر إيداع توثيقي:** `1e9b73d` — مواءمة سجلات الترحيلات والحالة والاختبارات.
**نطاق المراجعة:** مراجعة مصدرية، تطابق المخطط والترحيلات، RLS، المسارات الحساسة، الاختبارات، النشر، وفحص إنتاجي للقراءة فقط. لم يُنشأ حجز أو حساب أو ملف مريض، ولم تُرسل رسالة SMS أو تُغيّر خطة أو إعداد هوية حساس في هذه الجولة.

> لا يمكن لأي مراجعة تقنية إثبات انعدام الأخطاء أو الثغرات المستقبلية نظرياً. يثبت هذا التقرير فقط ما تم فحصه فعلياً والحدود التي لا يمكن تجاوزها من دون تهيئة خارجية أو اختبار معزول.

## 1. جرد الإجراءات المنفذة

يوثق سجل Git تسلسلاً من التحصينات والتصحيحات والتحسينات، تشمل حماية التسجيل والدخول ووجهات العودة، مهلات العمليات الخادمية، حراس الكتابة العامة، سجل OTP، عزل بيانات العيادات التجريبية، مهام Realtime، تقارير الإدارة، وفهارس وRLS قاعدة البيانات. يظل سجل الإيداعات هو المصدر التفصيلي القابل للتتبع لهذه الأعمال.[1]

| المجال | الإجراء المطبق | دليل التحقق |
|---|---|---|
| الحجز والبيانات الحساسة | إجراءات خادمية ذرية، مفاتيح idempotency، انتقالات حالة مضبوطة، والتحقق من ملف المريض والهاتف قبل الحجز. | عقود الحجز واختبارات الوحدة والمتصفح.[2] |
| الوصول والصلاحيات | RLS تفصل نطاق المريض والعيادة والإدارة؛ القراءة العامة لا تكشف كيانات عيادة تجريبية. | ترحيلات الإنتاج واختبارات منع القراءة العامة.[3] [4] |
| الاستمرارية | مهلة تشغيلية 15 ثانية للمسارات الحساسة وعمليات الهوية والقراءات والكتابات المهمة؛ الفشل يتحول إلى استجابة آمنة. | طبقة العمليات وتقرير الاختبار.[5] |
| وجهات العودة والكتابات العامة | حارس أصل وحجم للطلبات العامة، وحارس لوجهات العودة الداخلية مع فك ترميز متكرر محدود. | اختبارات التحقق ودليل الفحص الحي.[6] |
| الواجهة وPWA | مسارات مقارنة عربية وإنجليزية، PWA، رؤوس حماية، وفشل اتصال آمن. | Playwright وفحص الإنتاج.[2] [7] |
| النشر والتوثيق | فرع `main` مرفوع، وسجل الترحيلات البعيد موثق حتى الترحيل رقم 80. | Git وسجل Supabase.[3] |

## 2. نتائج مراجعة التكرار والتعارض

أُجري مسح ساكن لعمليات قاعدة البيانات والهوية، ومصارف التحويل، وأنماط التنفيذ الخطرة، والمسارات المتكررة. لا توجد مسارات App Router مكررة، ولم يظهر استخدام لـ `eval` أو `new Function` أو حقن HTML مباشر، ولم يظهر مفتاح حساس مكشوف في كود التطبيق. المراجع الظاهرة لمفاتيح الخدمة محصورة في مصنع عميل الإدارة وفحص الجاهزية وأداة فحص الأسرار ومحاكي اختبار لا يعمل من دون مفتاح خدمة محلي.

أظهر فحص تطابق أنواع Supabase عيباً مثبتاً واحداً: كان `lib/database.types.ts` يفتقد عقد RPC `complete_patient_phone_verification_server` الموجود فعلياً في مخطط الإنتاج. أدى ذلك إلى عقد TypeScript محلي مكرر داخل مسار تأكيد الهاتف. تمت مزامنة الأنواع الحية وإزالة العقد المحلي؛ لذلك أصبح مسار RPC معتمداً على مصدر النوع المولد الواحد. اجتاز التعديل فحص الأنواع والتحليل والاختبارات الكاملة.[8]

| النتيجة | الحالة | المعالجة |
|---|---|---|
| انجراف نوع RPC للتحقق الهاتفي | **تم إصلاحه** | تحديث `lib/database.types.ts` وإزالة التحويل المحلي من مسار التأكيد في الإيداع `a2d2520`. |
| سجل الترحيلات المحلي مقابل البعيد | **تمت مواءمته** | أضيف الترحيل البعيد رقم 80 `consolidate_rls_policy_execution_paths` بإصدار `20260821090031` إلى السجل. |
| تداخل سياسات RLS | **تمت معالجته سابقاً ومراجعته** | سياسة واحدة لكل إجراء مصادق عليه في الجداول المستهدفة، مع إبقاء اتحاد نطاقات الأدوار. |
| مسارات مكررة أو حقن برمجي ظاهر | **لم يثبت وجود عيب** | لا توجد نتيجة تستلزم تغييراً برمجياً. |

| فحص أصل PWA المقيد | نجاح 100% عند 5 و25 و50 طلباً متزامناً | أصل ثابت للقراءة فقط، ولا يقيس حجزاً أو API أو قاعدة بيانات أو سعة تجارية. عند 50 طلباً: P50 `1963.32ms`، P95 `2323.69ms`، P99 `2910.53ms`. |

## 4. الحالة الإنتاجية والقيود الصريحة

النسخة المرتبطة بالإيداع `a2d2520` نشرت بنجاح على Vercel، فيما أحدث إيداع توثيقي على الفرع الرئيسي هو `1e9b73d`. عيّنات العيادات التجريبية لا تظهر في البحث العام عمداً، لذلك لا يجوز تقديمها للمرضى كعيادات حقيقية. كما أن عدم ظهور نتائج عامة في حالة عدم وجود عروض عيادات حقيقية منشورة ليس خللاً في المقارنة؛ بل هو نتيجة حماية فصل البيانات التجريبية عن الجمهور.[4]

| القيد | سبب عدم تجاوزه تلقائياً | الإجراء المطلوب خارج الكود |
|---|---|---|
| SMS/OTP حقيقي | أسرار Twilio غير مضبوطة في Vercel؛ المسار يعيد `503` آمنة قبل الكتابة. | إضافة أسرار Twilio ثم إجراء اختبار SMS واحد مقصود وموافق عليه. |
| منع كلمات المرور المسرّبة | Supabase تعرضه كميزة خطة Pro أو أعلى، والمشروع على Free. | قرار ترقية منفصل ثم تفعيل الإعداد وإعادة الفحص. |
| ضوابط تغيير كلمة المرور المجانية | خيارا إعادة المصادقة وكلمة المرور الحالية كانا معطلين في اللوحة عند الفحص. | تأكيد صريح لتعديل إعداد الهوية، لأنه يغير تجربة المستخدم عند تغيير كلمة المرور. |
| اختبار أحمال كبيرة/متزامنة | غير مناسب ولا مثبت على الإنتاج؛ الفحص الحالي مقيد بأصل PWA ثابت. | بيئة معزولة، بيانات مصطنعة مصرح بها، SLOs ومراقبة وتكلفة متفق عليها. |
| محاكاة مصفوفة الأدوار محلياً | أداة المحاكاة تتطلب مفتاح خدمة Supabase غير موجود محلياً. | تهيئة بيئة اختبار معزولة ومفتاح خدمة خاص بالاختبار، لا استخراج سر إنتاج. |

## 5. الخلاصة

تمت معالجة العيب المثبت الوحيد الذي ظهر في هذه المراجعة، وهو انجراف نوع RPC، كما صُحح سجل الترحيلات لتطابق قاعدة الإنتاج. لا توجد نتيجة من المسح أو بوابات الجودة أو فحص الإنتاج الحالي تثبت كسر مسار أو تكرار طريق أو تسريب بيانات عامة أو خطأ تشغيل حديث. لا تُحوّل هذه النتيجة القيود الخارجية إلى نجاحات مزعومة: إرسال SMS الحقيقي، حماية كلمات المرور المسرّبة، الاختبارات المصرح بها للأدوار، واختبار الأحمال التجارية تتطلب قرارات أو تهيئة خارجية مستقلة.
