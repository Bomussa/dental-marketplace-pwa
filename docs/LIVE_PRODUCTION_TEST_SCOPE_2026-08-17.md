# نطاق اختبار الإنتاج الحي المكثف — 17 أغسطس 2026

## النطاق المستهدف

سيقتصر الاختبار على النطاق الرئيسي `https://www.mmc-mms.com` والروابط المتفرعة منه. ستوزع المسارات المستقلة على مجموعات الاختبار التالية:

| المجموعة | المدخلات الحية | مستوى الأثر |
|---|---|---|
| الواجهة العامة | الصفحة الرئيسية، اللغة العربية والإنجليزية، قوائم العلاج والنوع والموعد، زر النتائج، النصوص والروابط العامة | قراءة وتفاعل واجهة فقط |
| النتائج وPWA | بحث صالح، بحث غير صالح، الحالة الفارغة، `manifest.webmanifest`، `sw.js`، `offline.html`، أيقونات PWA | قراءة فقط |
| الحماية | `/account`، `/clinic`، `/admin`، `/login`، وطلبات API غير الموثقة أو غير الصالحة | بلا إنشاء بيانات |
| واجهات الخدمة | `/api/health`، وطلبات تحقق سالبة إلى البحث والحجز والتحليلات والدعم | بلا إنشاء بيانات |
| التزامن المضبوط | الصفحة الرئيسية، الصحة، البحث، الأصول العامة، ومسارات الحماية باستخدام GET أو أجسام غير صالحة فقط | لا حجوزات، لا رسائل، لا سجلات تشغيلية مقصودة |

## حدود السلامة

لن يُرسل رابط دخول إلى بريد حقيقي، ولن يُنشأ حجز أو بلاغ أو حدث تحليلي صالح أو جهاز أو رسالة دعم. سيقتصر حمل التزامن على طلبات عامة آمنة، بمعدل متدرج ومحدود مع توقف تلقائي عند ملاحظة أخطاء `5xx` أو ارتفاع زمني غير طبيعي. لا يمثل هذا اختبار سعة قصوى أو هجوم ضغط، بل تحقق تحمّل وظيفي محافظ على خدمة المستخدمين الحقيقيين.
