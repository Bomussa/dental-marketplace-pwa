# خطة رجوع آمنة لتحديث واجهة المنصة

## نطاق الحماية

يقتصر تحديث الواجهة على نظام الأنماط والمكوّنات المشتركة والتنقل والتوثيق واختبارات الانحدار. لم تُغيّر جداول قاعدة البيانات أو ترحيلاتها أو سياسات RLS أو واجهات البرمجة أو مسارات المصادقة أو عقود الحجز. لذلك لا تتطلب العودة إلى التصميم السابق أي تعديل على بيانات المرضى أو العيادات أو المخطط.

| الأصل | المرجع | الغرض |
|---|---|---|
| النسخة السابقة للتصميم | `c87c627` | مرجع Git السابق لتحديث واجهة المستخدم. |
| نسخة مراجعة الواجهة في بيئة المشروع | `d631d350` | استعادة النسخة المتحققة من نظام التصميم الجديد عند الحاجة. |
| مستودع العمل | `Bomussa/dental-marketplace-pwa` | مصدر النشر الذي يجب أن يستقبل التراجع أو التحديث. |

## متى يُنفّذ الرجوع

يبدأ الرجوع فقط عند ظهور عيب مرئي أو وظيفي مؤكد في بيئة النشر، مثل قص محتوى على جهاز مدعوم، انخفاض قابلية القراءة، تعذر إتمام البحث أو تسجيل الدخول، أو اعتراض صاحب المنتج على التوجه البصري بعد المراجعة. لا يُستخدم الرجوع لمعالجة ملاحظة بسيطة يمكن تصحيحها بإصلاح محدود ومختبر.

## المسار الموصى به

> استخدم **Git revert** ولا تستخدم `git reset --hard`، حتى يبقى تاريخ النشر قابلاً للتدقيق وتبقى أي تغييرات لاحقة للمطورين الآخرين سليمة.

1. أوقف نشر أي تغيير واجهة إضافي مؤقتًا، ثم افتح بلاغًا يصف الشاشة والعرض والجهاز وخطوات إعادة المشكلة.
2. أعد تشغيل فحوصات `typecheck` و`lint` و`test` و`build` واختبارات المتصفح لتحديد إن كان العيب محصورًا في تغيير صغير.
3. إذا تأكد أن الرجوع الكامل مطلوب، أنشئ التراجع في المستودع الأصلي عبر الأمر `git revert --no-edit <معرف_التحديث_المرئي>`، ثم ادفع الالتزام الناتج إلى الفرع المنشور من خلال مسار النشر المعتاد.
4. نفّذ فحصًا دخانيًا بعد النشر للمسارات `/` و`/results` و`/login`، وتحقق من انتقال `/account` و`/clinic` و`/admin` للمستخدم غير المصرح له، من دون إدخال بيانات أو إرسال نموذج.
5. لا تُنفذ أي ترحيلات قاعدة بيانات أو حذف بيانات أثناء الرجوع، لأن تحديث الواجهة لا يتطلب ذلك.

## خيار الاستعادة من نسخة المشروع

إذا كان العيب داخل مساحة المشروع قبل تصدير التغيير إلى المستودع، يمكن استعادة الإصدار `d631d350` من سجل النسخ في واجهة إدارة المشروع للعودة إلى النسخة المتحققة من التصميم الجديد. أما العودة إلى التصميم السابق للمستودع الأصلي فتبقى عبر تراجع Git إلى المرجع السابق `c87c627` أو عبر التزام تراجع مكافئ.
