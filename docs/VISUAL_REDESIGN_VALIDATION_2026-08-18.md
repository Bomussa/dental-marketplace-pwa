# التحقق البصري لإعادة التصميم — 18 أغسطس 2026

تمت مراجعة الشاشة الرئيسية محليًا باللغتين العربية والإنجليزية بعد إعادة بناء طبقة الهوية. ظهرت الخلفية الفنية الطبية، التدرج الداكن، السطوح الزجاجية، البحث البارز، والأزرار المتباينة بصورة متماسكة، مع بقاء حقول البحث والروابط والخيارات التشغيلية نفسها دون تغيير.

| النطاق | النتيجة المرصودة |
|---|---|
| العربية | اتجاه RTL، النص الرئيس، حقل البحث، الشارات، وتدرجات السطح واضحة ومتوازنة. |
| الإنجليزية | اتجاه LTR، التسلسل البصري، المحتوى النصي، ومواضع عناصر البحث متوازنة. |
| الحركة | الخلفية تستخدم حركة انسيابية تراعي إعداد تقليل الحركة في النظام. |
| الخصائص | لم يتغير استعلام العلاج أو النوع أو الموعد أو زر عرض النتائج أو ترتيب الموقع. |

تم فتح صفحة النتائج من النموذج الجديد محليًا بنجاح؛ بقيت معلمات البحث كما هي، وظهرت بطاقة قرار داكنة وشريط سياق وتحديث حي وسطح حالة فارغة مقروء. اجتازت النسخة النهائية فحص النشر والأنواع والتدقيق و50 اختبار وحدة وبناء الإنتاج. جرى تحويل خلفية البطل إلى WebP بحجم 148 كيلوبايت لتقليل أثر التحميل.
