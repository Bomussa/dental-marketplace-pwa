## تحديث تحقق التنفيذ — 15 أغسطس 2026

تم تطبيق هجرة `exclude_synthetic_dev_clinics_from_public_search` على مشروع DEV المتصل، ثم تصحيح صلاحية دالة البحث لتعمل تحت دور `anon` مع `search_path` ثابت، من دون منح هذا الدور وصولًا مباشرًا إلى `verification_records`. أعاد الاستعلام تحت دور `anon` صفر صفوف لخدمة «علاج عصب — ضرس» التي كانت تعرض سجلات DEV، وتحققت النتيجة نفسها على الموقع المنشور مباشرةً: أصبحت النتيجة العامة **0 عروض** مع رسالة صادقة لا تنفي وجود الخدمة في قطر.

كما أضيفت حماية لمسار إدخال أحداث القرار تشمل `Origin` صريحًا، سقفًا لحجم الحمولة، وحدًا مؤقتًا للطلبات في طبقة الخادم؛ وأضيفت اختبارات لحارس الإدخال ولمفتاح idempotency الثابت. أُصلح اختبار E2E المتقادم، وأضيفت مضاهاة هاتف، وأضيفت بوابة CI لا تستخدم أسرار خدمة.

| التحقق بعد التنفيذ | النتيجة |
| --- | --- |
| TypeScript + ESLint + Vitest + Production Build | **PASS** عبر `npm run verify` مع متغيرات عامة مؤقتة صالحة الشكل. |
| اختبارات Playwright على سطح المكتب والهاتف | **PASS**: 4 اختبارات نجحت باستخدام بيانات الاعتماد العامة المؤقتة لمشروع DEV وChromium المثبت محليًا. |
| دالة البحث تحت `anon` | **PASS**: لا خطأ وصول إلى `verification_records` ولا عودة لسجلات DEV. |
| الموقع الحي بعد الهجرة | **PASS**: لم تظهر بطاقات `DEV Dental *` في رابط البحث الذي كان يكشفها سابقًا. |

> يظل هذا إنجازًا لتحصين سطح DEV المنشور، وليس تحويلًا للنطاق إلى Production تجاري. لا تزال الحاجة قائمة لبيئة Production مستقلة وبيانات عيادات حقيقية موثقة واختبار Magic Link فعلي وحمل حجز متزامن.
