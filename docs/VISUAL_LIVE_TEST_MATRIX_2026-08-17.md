# مصفوفة الاختبار البصري الحي — الموقع الرسمي

## العناصر العامة المستهدفة

| الشاشة أو المجموعة | العناصر التي ستختبر بصريًا ووظيفيًا |
|---|---|
| الصفحة الرئيسية | شعار العودة للرئيسية، رابط العيادات، تبديل اللغة، رابط الدخول، اختيار العلاج، اختيار النوع الدقيق، اختيار الموعد، زر النتائج، زر الموقع، بطاقات المعلومات، إدخال سؤال المساعد، زر الإرسال. |
| نتائج البحث | عنوان العلاج والنوع، وصف معايير الفرز، حالة النتائج أو الحالة الفارغة، رابط بحث جديد، العناوين والتذييل. |
| الدخول والحماية | واجهة رابط الدخول، حقل البريد، زر الإرسال بصيغة إدخال غير صالحة فقط، وتوجيهات `/account` و`/clinic` و`/admin` للزائر غير المسجل. |
| PWA والأصول | بيان التطبيق، عامل الخدمة، أيقونات التطبيق، وصفحة عدم الاتصال العامة. |
| الواجهات الخدمية | الصحة، البحث غير الصالح، الحجز غير الموثق، التحليلات غير الصالحة، الدعم غير الموثق. |

## حدود الإثبات

لا تشمل هذه الجولة إنشاء حجوزات أو إرسال رابط دخول أو رسائل دعم أو أحداث تحليلات صالحة، ولا اختبارات الإدارة والعيادة والحساب بعد تسجيل الدخول. تتطلب هذه الوظائف حسابات مخصصة وصلاحيات فعلية وبيانات عرض مؤهلة؛ ستوثق بوصفها مسارات محمية لا كعناصر متروكة أو غير مختبرة.

## ملاحظة تنفيذية أثناء الاختبار

أظهرت المحاولة الأولى لإدخال سؤال عربي عبر واجهة الاختبار أن الحقل بقي فارغًا عند الإرسال، فطبّق المتصفح تحقق `required` المحلي ولم يرسل طلبًا إلى الخادم. لا تمثل هذه النتيجة عيبًا مؤكدًا في التطبيق؛ ستعاد المحاولة بمدخل قصير ثم تتحقق قيمة الحقل قبل الإرسال.
