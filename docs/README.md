## سجلات تاريخية

تقارير الاختبارات والاكتشاف والتحميل والهوية وPWA الموجودة هنا — مثل `COMPLETION_VERIFICATION_*` و`DELIVERY_VERIFICATION_*` و`LIVE_*` و`WIDE_AUDIT_*` و`VISUAL_*` — تحفظ الدليل التاريخي لنتيجة أو مرحلة في تاريخها. لا تُحذف ولا يعاد تحرير حقائقها بأثر رجعي. عند تعارضها مع README الجذري، تُقرأ كتقرير زمني ولا تغيّر الحالة الحالية.

## سياسة التحديث

أي إضافة لمسار أو عقد API أو جدول أو دالة أو متغير بيئة أو قيد تشغيلي يجب أن تحدّث [README الجذري](../README.md) في الإيداع نفسه. أي اختبار أو نشر جديد يضيف تقريرًا مؤرخًا يربط من هذا الفهرس فقط عندما يمثّل حالة مرجعية جديدة.
