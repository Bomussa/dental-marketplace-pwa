# الحالة الإنتاجية الحالية — أسناني قطر / MMC-MMS

**آخر مراجعة موثقة:** 19 أغسطس 2026. هذا الملف هو موجز الحالة التشغيلية الحالية، ويُقرأ مع [README الجذري](../README.md). لا يعيد كتابة التقارير المؤرخة السابقة؛ تلك تبقى أدلة لزمنها ونطاقها فقط.

> **النطاق الرسمي:** [www.mmc-mms.com](https://www.mmc-mms.com) و[mmc-mms.com](https://mmc-mms.com). التطبيق منصة مقارنة وطلبات حجز؛ ليس جهة تشخيص أو علاج، ولا ينشئ اختبار التشغيل حجزاً أو رسالة SMS حقيقية.

## الإصدار والتحقق الأخير

| البند | الحالة المثبتة |
|---|---|
| إيداع الواجهة والبحث الحالي | `65f5cd0` — `feat: unify search contract and expose distance range`. |
| حالة النشر | إصدار الإنتاج المرتبط بالإيداع في Vercel بحالة `READY`. |
| بوابة الجودة | `npm run verify` نجح: فحص مسبق، TypeScript، ESLint، 64 اختبار وحدة، وبناء إنتاجي. |
| اختبار المتصفح | `npm run test:e2e` نجح: 50 اختباراً لمسارات سطح المكتب والهاتف، بما فيها رفض تسجيل الخروج من أصل خارجي. |
| صحة الإنتاج | `/api/health` أعاد `ok=true` و`database=true` و`server_operations=true` في آخر فحص حي موثق. |
| بحث حي | نطاق 25 كم ظهر في نموذج المقارنة وحُفظ في رابط النتيجة وملخصها. يرفض `/api/search` تفضيل موعد غير صالح بحالة `400`. |

## السلوك التشغيلي الحالي

| المجال | الضمان المطبق |
|---|---|
| البحث والمقارنة | يختار الزائر علاجاً رئيسياً ثم نوعاً دقيقاً، وتفضيل موعد، ونطاقاً من 1 أو 5 أو 10 أو 25 أو 50 كم، ومعيار ترتيب. عقد التحليل موحّد للصفحة وواجهة API. |
| الترتيب | «أفضل توازن شامل» معيار مستقل موزون للسعر والتقييم والموعد والمسافة؛ لا يكرر «الأرخص أولاً». |
| الحجز | يبدأ فقط من موعد صالح وبمفتاح idempotency وملف مريض مكتمل وهاتف موثق. انتقالات الحجز الحساسة خادمية وذرية. |
| تقارير النشاط | الإدارة ترى نطاق المنصة، والمالك/المدير في العيادة يرى نطاق عيادته فقط. التجميع بالساعة أو اليوم أو الأسبوع أو الشهر بتوقيت `Asia/Qatar`، مع طباعة؛ تصدير CSV إداري فقط. |
| التحديث اللحظي | الجداول التشغيلية المصرح بها منشورة على Realtime، والواجهات تستخدم سياسة تجميع وإعادة اتصال موحدة؛ لا تتجاوز RLS. |
| الكتابات العامة والجلسة | مسارات الحجز والتسجيل وOTP والدعم وتثبيت الجهاز والتحليلات تتحقق من المصدر نفسه وحد الحجم ومعدلات الطلب قبل الكتابة. تسجيل الخروج يرفض أيضاً الأصل الخارجي قبل إنهاء الجلسة. |
| بيانات حساسة | RLS هو طبقة فرض الوصول. سياسات التعديل العميلية المباشرة للحجوزات والدعم وتغيير حالة المراجعة مسحوبة؛ المسارات الخادمية المقيّدة هي الطريق التشغيلي المعتمد. |

## القيود الصريحة

لا يصح اعتبار أي تطبيق خالياً نظرياً من كل خطأ أو ثغرة مستقبلية. لا يدّعي هذا التقرير اختبار تحميل بحجوم الآلاف أو الملايين، ولا إثبات إرسال SMS ما لم يجهّز مزود Twilio لاختبار مقصود. لاحظ التدقيق السابق استقراراً كاملاً حتى 150 طلباً متزامناً على ملف ثابت واختبر حدّاً عند 250 طلباً متزامناً؛ لا يُعتمد مستوى أعلى من ذلك قبل اختبار أداء خارجي مخصص. حماية كلمات المرور المسرّبة لدى Supabase ما زالت ميزة مرتبطة بخطة أعلى من الخطة الحالية؛ لم تُجرَ ترقية أو تكلفة تلقائية.
