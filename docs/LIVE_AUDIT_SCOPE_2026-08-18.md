# نطاق تدقيق الموقع الحي — 18 أغسطس 2026

## مبدأ الإثبات

لا يعتمد هذا التدقيق على افتراضات أو تقييمات عامة. لن يُدرج أي بند بوصفه ناجحًا إلا إذا كان له دليل مباشر: نتيجة طلب حي، أو تشغيل اختبار، أو لقطة شاشة من الموقع الرسمي، أو نتيجة موثقة من بيئة النشر. أما المسارات المحمية أو الميزات التي تتطلب بيانات اعتماد خارجية فستوسم صراحةً بأنها **غير قابلة للتحقق دون الحساب أو الإعداد المطلوب**، لا بأنها ناجحة.

## عينات مرجعية، لا نسخ أو ادعاء شمول

راجع التدقيق ثلاث خدمات صحية عامة رسمية بوصفها عينات مرجعية لتجربة الحجز، ولا يدّعي مراجعة «كل التطبيقات العالمية». المبادئ القابلة للنقل هي إظهار التوافر بوضوح، جعل خطوة الحجز التالية صريحة، بيان الثقة والاختصاص في النتائج، وتقديم مسار واضح لإدارة الموعد. لا تنسخ العلامات التجارية أو النصوص أو الواجهة الخاصة بأي خدمة.

| المصدر الرسمي | المبدأ المستخلص القابل للتدقيق | الرابط |
|---|---|---|
| Zocdoc | تعرض النتائج التخصص والتقييم والتوافر القادم وزر الحجز المباشر. | [Zocdoc](https://www.zocdoc.com/) |
| Doctolib | تقدم خدمة الحجز والإدارة في مسار قصير وتدعم لغات متعددة. | [Doctolib](https://www.doctolib.de/?locale=en) |
| NHS App | تفصل بين الحجز وإدارة المواعيد، وتوضح بجلاء ما يحدث عند عدم توافر الموعد. | [NHS App](https://www.nhs.uk/nhs-app/help/appointments/gp-surgery-appointments/) |

## مصفوفة التحقق

| المجال | دليل القبول المطلوب | حد التدقيق |
|---|---|---|
| المسارات العامة | حالة HTTP متوقعة ومحتوى حي أو إعادة توجيه مقصودة. | الصفحة الرئيسية، البحث، النتائج، البيان وواجهة الصحة. |
| الهوية البصرية | لقطة شاشة فعلية مع فحص التسلسل البصري، التباين، لغة الواجهة، والمسافات. | سطح المكتب والهاتف للصفحات العامة. |
| الأزرار والأيقونات | كل عنصر تفاعلي مرئي له هدف واضح ويؤدي إلى انتقال أو حالة متوقعة. | العناصر المتاحة للزائر فقط، دون إنشاء حجوزات أو رسائل. |
| العربية والإنجليزية | اتجاه صحيح، نصوص صريحة، وعدم وجود مفاتيح ترجمة أو حروف تالفة في المسارات المفحوصة. | واجهات اللغة التي يوفرها الموقع فعليًا. |
| الأداء والموثوقية | قياس حي محدود للطلبات العامة فقط، مع تمييزه عن اختبار حمل معاملات أو جلسات مستخدمين. | لا توجد كتابة أو حجز أو SMS. |
| المسارات المحمية | إثبات إعادة التوجيه للزائر فقط. تتطلب المحاكاة الكاملة دخولًا مفوضًا من صاحب الحساب. | `/account` و`/clinic` و`/admin`. |
| SMS الفعلي | لا يوسم ناجحًا إلا بعد إعداد أسرار مزود الرسائل وإجراء اختبار برقم يملكه المستخدم. | لا إرسال أثناء التدقيق الحالي. |
