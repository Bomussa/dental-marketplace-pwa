# نطاق اكتشاف إعادة البناء

| مسار الفحص المستقل | مدخلات الفحص |
|---|---|
| رحلة الحجز | صفحة النتائج، واجهة الحجز، التحقق، واجهة API، دوال قاعدة البيانات، واختبارات الحجز. |
| هوية المريض والخصوصية | جداول المستخدمين والحجوزات وسياسات RLS والمصادقة ومواقع عرض بيانات المريض. |
| مساحة المركز | صفحة العيادة، العضويات، العروض والمواعيد، التعديلات المسموحة، والإشعارات الحالية. |
| مساحة الإدارة | الصفحة والأفعال الخادمية وصلاحيات `platform_admin` والوظائف التشغيلية. |
| التحديث اللحظي | قنوات Supabase Realtime والجداول المنشورة ومصادر الحقيقة ومنع التعارض. |
| الهوية والتجربة | التخطيط العام، مكونات الواجهة، الرموز، الألوان، الخطوط، والاستجابات على الشاشات الأساسية. |
