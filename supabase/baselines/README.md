# Asnani current-schema baseline

هذا المسار هو **baseline snapshot** قابل لإعادة البناء من دون بيانات صفوف أو مستخدمي Auth أو كلمات مرور أو مفاتيح أو جلسات. يعالج فجوة أن أول 15 مهاجرة تاريخية غير موجودة ماديًا في المستودع، كما هو موثق في [`../REMOTE_APPLIED_MIGRATIONS.md`](../REMOTE_APPLIED_MIGRATIONS.md).

## المحتويات

| الملف | الغرض |
|---|---|
| `20260825000000_asnani_current_schema_snapshot.sql` | لقطة مصدرية خالية من البيانات للمخطط المرجعي قبل دلتا تقوية صلاحيات RPC، وتشمل الامتدادات والجداول والدوال والقيود والفهارس والمشغلات وRLS والسياسات ومنح الصلاحيات الصريحة التي كانت قائمة وقت الاسترداد. |
| `../../supabase/migrations/20260825191000_harden_public_function_execute.sql` إلى `20260825195000_allow_authenticated_search_rpc.sql` | دلتا أمنية لاحقة ومرتبة؛ تحصر تنفيذ الدوال، ثم تعيد منح مسار البحث العام ومساعد التحقق الضروري فقط. |
| `../../scripts/generate-schema-baseline.py` | مولد محلي لا يتصل بقاعدة بيانات؛ يحول لقطات كتالوج DDL فقط إلى baseline. |
| `../../scripts/verify-schema-baseline.py` | متحقق يقارن هوية كائنات البناء مع لقطة الكتالوج: الجداول والدوال والقيود وRLS والسياسات والفهارس والمشغلات والامتدادات، ويستطيع استبعاد مقارنة منح اللقطة الأصلية عندما تكون دلتا التقوية مقصودة. |

## قاعدة الاستخدام

> هذا المسار بديل لإعادة بناء قاعدة **جديدة** فقط. لا يُطبّق فوق قاعدة تحمل المسار التدريجي التاريخي، ولا يُدمج في `supabase/migrations/` الحالية حتى لا يعاد إنشاء كائنات موجودة.

لإعادة بناء **الحالة الآمنة الحالية** في مشروع Supabase محلي جديد، انسخ baseline ثم طبّق، بالترتيب وبدون أي مهاجرات تاريخية أخرى، الملفات التالية:

| الترتيب | migration |
|---:|---|
| 1 | `20260825191000_harden_public_function_execute.sql` |
| 2 | `20260825192500_revoke_anon_server_rpc_execute.sql` |
| 3 | `20260825193500_limit_authenticated_security_definer_rpc.sql` |
| 4 | `20260825194500_allow_public_search_validation_helper.sql` |
| 5 | `20260825195000_allow_authenticated_search_rpc.sql` |

يشغّل الاختبار المحلي baseline مع هذه الدلتا فقط في دليل مؤقت، ثم يقارن هوية الكائنات. لا تُقارن منح baseline الأصلية حرفيًا بعد الدلتا، لأنها حُصرت عمدًا؛ استخدم المتحقق بخيار `--skip-grants`، ثم افحص postconditions الأمنية أدناه.

## آخر تحقق محلي للحالة المقواة

أعاد البناء المعزول بعد تطبيق baseline والملفات الخمسة أعلاه بنجاح. بقيت هوية المخطط مطابقة: **49 جدولًا، 75 دالة، 321 قيدًا، 49 جدول RLS، 104 سياسات، 116 فهرسًا غير مقيد، 42 مشغلًا، و6 امتدادات مقصودة**.

| postcondition | النتيجة المطلوبة |
|---|---|
| `anon` ينفذ `search_dental_offers` | مسموح |
| `authenticated` ينفذ `search_dental_offers` | مسموح |
| `anon` ينفذ `is_price_scope_publishable` | مسموح، لأنه مساعد قراءة مطلوب لمسار البحث العام |
| `anon` أو `authenticated` ينفذ `book_slot_server` | ممنوع |
| `service_role` ينفذ `book_slot_server` | مسموح لمسار API الخادمي فقط |

لا تُحفظ لقطات الكتالوج التشغيلية التي استُخدمت أثناء الاسترداد في Git؛ فهي أدلة محلية خالية من الصفوف وتخضع للحد الأدنى من الاحتفاظ. عند الحاجة إلى تحديث baseline مستقبلًا، يجب إعادة استخراج الكتالوج من البيئة المرجعية عبر قراءة فقط، ومراجعة الفروقات، وإعادة اختبار البناء المحلي قبل تحديث هذا الملف.
